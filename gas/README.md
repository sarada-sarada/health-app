# エストラーナ通知 — Googleカレンダー連携の設定手順

健康管理アプリで「貼り替えた ✓」を押すと、Googleカレンダーの通知予定（19:30／20:30の念押し）が
「貼った日の2日後から2日おき」に自動で付け直されるようにする設定です。最初に1回だけ行います（約10分、パソコン推奨）。

## 1. スクリプトを作る（パソコン）

1. パソコンのブラウザで https://script.google.com を開き、カレンダーを使っているGoogleアカウントでログインする
2. 左上の「**＋ 新しいプロジェクト**」をクリック
3. 左上の「無題のプロジェクト」をクリックし、名前を「**エストラーナ通知**」にする
4. エディタに最初から入っている `function myFunction() { … }` を**すべて消し**、
   [gas/Code.gs](https://github.com/sarada-sarada/health-app/blob/main/gas/Code.gs) の中身を**全部コピーして貼り付ける**
   （GitHubのページ右上のコピーボタンでまとめてコピーできます）
5. 11行目あたりの `const TOKEN = 'ここに合言葉を入れる';` の `ここに合言葉を入れる` を、自分で決めた**合言葉**に書き換える
   （英数字12文字以上がおすすめ。この合言葉は他人に見せない）

## 2. カレンダーを使えるようにする

1. 左側の「**サービス**」の右にある「**＋**」をクリック
2. 一覧から「**Google Calendar API**」を選び、「**追加**」をクリック（IDは `Calendar` のまま）
3. 上の💾（プロジェクトを保存）をクリック
4. 上部の関数の選択欄で「**authorize**」を選び、「**▷ 実行**」をクリック
5. 「承認が必要です」→「**権限を確認**」→ 自分のアカウントを選ぶ
6. 「Googleでこのアプリが確認されていません」と出たら、「**詳細**」→「**エストラーナ通知（安全ではないページ）に移動**」→「**許可**」
   （自分で作ったスクリプトなので問題ありません）
7. 下の実行ログに「カレンダーへのアクセスを確認しました」と出ればOK

## 3. ウェブアプリとして公開する

1. 右上の「**デプロイ**」→「**新しいデプロイ**」
2. 「種類の選択」の⚙️から「**ウェブアプリ**」を選ぶ
3. 次のように設定して「**デプロイ**」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（アプリから呼び出すために必要。合言葉がないと動かないようにしてあります）
4. 表示された「**ウェブアプリのURL**」（`https://script.google.com/macros/s/…/exec`）をコピーする
5. URLと合言葉を、自分宛てのメールやメモなどでiPhoneに送る

## 4. アプリに設定する（iPhone）

1. 健康管理アプリを開き、ホームの「💊 エストラーナテープ」カードの一番下「**📅 カレンダー連携：未設定**」をタップ
2. 「スクリプトのURL」と「合言葉」を貼り付けて「**保存する**」
3. 「**今の記録でカレンダーを同期**」をタップ
4. 「📅 カレンダーも更新しました（次回 ◯月◯日）」と出れば完了

以後は「貼り替えた ✓」を押すたびに、カレンダーの予定も自動で付け直されます。

## 補足

- 過去の予定はカレンダーに残り、貼った日以降の予定だけが差し替わります。
- 記録を✕で削除したときも、残っている最新の記録に合わせて付け直されます。
- スクリプトを書き換えたときは「デプロイ」→「デプロイを管理」→ ✏️ →「バージョン：新バージョン」→「デプロイ」で反映します（URLは変わりません）。
- 通知の時刻を変えたいときは、`Code.gs` の `time: '19:30'` などを書き換えて上の手順で反映します。
